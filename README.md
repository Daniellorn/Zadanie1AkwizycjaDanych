

# Projekt: Indekser i Wyszukiwarka

## Instalacja

Przed pierwszym uruchomieniem zainstaluj wymagane biblioteki znajdujące się w pliku `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Uruchamianie

### 1. Indeksowanie dokumentów

Aby uruchomić proces indeksowania, wykonaj poniższe polecenie w terminalu:

```bash
python Indekser.py
```

### 2. Wyszukiwanie

Aby wyszukać tekst lub słowa kluczowe, przekaż je bezpośrednio po nazwie skryptu:

```bash
python Wyszukiwarka.py wyszukiwany tekst
```
